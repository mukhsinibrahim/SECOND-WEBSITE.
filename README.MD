## 🛠️ Features Built-In
This single-page modern landing page includes:
* **Sticky Navigation Bar**: Smooth scrolling layout that links directly to page sections.
* **Responsive Project Cards**: An interactive CSS Grid card layout that adapts automatically to mobile phones and desktops.
* **Fade-In 'Scroll-to-Top' Button**: Pure JavaScript interaction that smoothly pops into view when users scroll down.
* **Custom Brand Color Palette**: Dark slate-blue aesthetic tuned to blend seamlessly with our brand logo.

## 💻 How to Run This Project Locally
No complex installation or servers are required. To view the website on your local machine:
1. Download or clone this project folder.
2. Make sure your logo image is saved in the `images` folder as `logo.png`.
3. Open the folder in **VS Code**.
4. Double-click the `kwanza.html` file or open it directly in any modern web browser (Chrome, Safari, Edge, or Firefox).
